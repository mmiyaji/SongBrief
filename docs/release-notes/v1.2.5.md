# SongBrief 1.2.5

## Changes

- Include confirmed outside-library history in Library song browsing, recent
  sorting and search. Label supplemental minimum counts and unavailable dates.
- Open supplemental songs in Apple Music rather than passing unsupported song
  IDs to the native library playback controls.
- Include supplemental plays consistently in Overview lifetime play, track,
  artist, album and estimated listening-time totals, favorite artists/albums,
  averages and cumulative artist/genre distributions.
- Include supplemental songs in the corresponding Overview drilldown lists,
  with minimum-count labels and safe external-song actions.
- Keep native skip counters and skip-rate denominators separate. Clearly scope
  registered-library collection/source metrics and preserve daily snapshots.
- Keep library membership authoritative when a supplemental song is later
  matched in the library, preventing duplicate rows and counts.

## TestFlight Test Notes

再生履歴の表示と概要の集計を改善しました。

概要の累計値と詳細一覧にも補完分が反映されることをご確認ください。
補完値は確認できた最低回数で、再生時間は曲長からの推計です。

## Validation and Limits

- Local Flutter suite: 336 tests passed; static analysis passed.
- Tests cover duplicate ingestion, matching native membership, supplemental
  search/browsing, cumulative totals and drilldowns, native skip metrics, unknown
  duration/date evidence, and a narrow screen with enlarged text.
- Native counters, library membership and persisted daily snapshots are not
  modified by display aggregates. Unknown play dates are not assigned to a day.
- Supplemental history remains a local record of confirmed minimum plays.
