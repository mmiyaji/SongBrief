# SongBrief 1.2.1

## Changes

- Preserve all eligible library tracks in foreground and background snapshots,
  local history, and iCloud merges instead of limiting each record to 500 tracks.
- Compress large iCloud records without dropping track counters. Oversized
  records remain local and pending when they cannot be uploaded safely.
- Refresh library statistics after foreground track transitions and more
  promptly after returning to the app.
- Supplement recent listening history with MusicKit recently played songs on
  iOS 16 and later, with metadata deduplication and current exclusion rules.
- Keep supplemental history separate from library counters, rankings, and daily
  snapshots to prevent duplicate play counts. Preserve unknown timestamps and
  cached history on request failures.

## TestFlight Test Notes

ライブラリの500曲制限を撤廃し、Apple Musicの最近の再生履歴による補完を追加しました。
履歴の重複表示、ライブラリ外の曲、日時不明の表示、更新後の再生回数をご確認ください。

## Validation and Compatibility

- Local Flutter suite: 278 tests passed; static analysis passed.
- Native RunnerTests: 41 tests passed on the CI iOS simulator before IPA upload.
- MusicKit automatic token generation requires the MusicKit App Service to be
  enabled for App ID `app.songbrief.songbrief`; remote configuration and actual
  account history retrieval require device verification.
- Older app versions cannot read compressed large iCloud payloads. Update all
  devices together when testing large libraries.
- Previously omitted counters cannot be reconstructed retroactively; newly
  included tracks need a subsequent comparable snapshot for daily changes.
