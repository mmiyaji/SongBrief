# SongBrief 1.2.8

## Changes

- Reduce loading-animation rebuilds and reuse the prepared phone navigation.
- Decode large native music-library and snapshot payloads in a background isolate.
- Build Playing panels and recent-history projections when they enter view; retain visited panel state.
- Split the overview chart and calendar into lazy panels, prepare history deltas in batches, and isolate weekly calendar repaints.
- Build year/day selection menus only when opened and improve year-label spacing and large-text layouts.
- Generate demo snapshot counters directly without rebuilding 90 complete library overviews.
- Show the app icon in the tablet sidebar and beside the phone title.
- Bundle the Web UI font and reduce Web-only blur/shadow costs; preserve native rendering effects.
