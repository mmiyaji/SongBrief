# SongBrief 1.2.2

## Changes

- Replace quadratic recent-history deduplication with indexed matching while
  preserving album editions, unknown-album matching, and newest representatives.
- Build provisional trend counters for the displayed song only. Cache historical
  lookups lazily by range and invalidate when data, song, locale, or date changes.
- Cache local lyrics results, including missing lyrics, briefly across tab visits.
- Pass downloaded MusicKit artwork directly to Flutter instead of decoding and
  re-encoding it on the main actor.
