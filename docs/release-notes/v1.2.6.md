# SongBrief 1.2.6

## Changes

- Show confirmed outside-library minimum plays in the listening calendar using
  their retained observation day when an exact playback date is unavailable.
  Label observation-day records separately; actual playback dates replace the
  fallback without increasing counts. Repeated observations do not add plays.
- Add a persisted, enabled-by-default setting to include outside-library history
  consistently in supported totals, history song lists, rankings and calendar.
  Disabling the setting retains stored history and ongoing collection.
- Include observed outside-library songs and updated library recency in Recent
  rankings, with observation dates clearly identified.
- Replace technical supplemental-history wording with user-facing explanations
  of outside-library history and confirmed minimum play counts.

## TestFlight Test Notes

ライブラリ外の再生履歴の集計とカレンダー表示を改善しました。
設定に「ライブラリ外の再生履歴も含める（推奨）」を追加しました。
確認できた再生回数を「履歴から確認：1回以上」のように表示します。
正確な再生日時が取得できない曲は、再生を確認した日として表示します。
設定をオフにしても履歴は保持され、オンに戻すと再び反映されます。

## Validation and Limits

- Local Flutter suite: 354 tests passed; static analysis passed.
- Supplemental records represent confirmed minimums, not a complete Apple Music
  play log. Unknown playback timestamps are never presented as exact play times.
- Native counters and daily snapshots remain unchanged. Supplemental history
  and this preference are stored locally.
- The setting applies to supported aggregate/history surfaces; native-only
  period rankings, recap/widgets and exports retain their existing scope.
- CI native RunnerTests: 41 tests passed; signed IPA verification passed.
