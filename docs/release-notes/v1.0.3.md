# SongBrief v1.0.3 Release Notes

Date: 2026-09-21

Version: 1.0.3

Source build: 4

Release type: Background recording, iCloud sync, widget, and statistics reliability

## Japanese Release Notes

バックグラウンド記録とiCloud同期の信頼性を改善しました。取得に失敗した場合の誤記録を防ぎ、未送信の記録を次回に再送します。複数端末での履歴削除と同時更新の処理、ウィジェットの更新、フィルター変更時の集計を修正しました。週・月レポートの期間判定を改善し、App Lockの認証エラー後に再試行できるようにしました。

## English Release Notes

Improved the reliability of background recording and iCloud sync. Failed library
queries no longer create misleading records, and pending uploads are retried.
This update also fixes history deletion and concurrent updates across devices,
widget refreshes, statistics after filter changes, weekly and monthly recap
boundaries, and retrying App Lock after authentication errors.

## TestFlight Test Notes

- Allow Music access for the first time and confirm that records and widgets update.
- Check background records and queued uploads after a period without connectivity.
- On two updated devices, clear history or remove old records, sync both devices,
  and confirm that deleted observations stay removed while newer captures survive.
- Change exclusion rules and confirm that comparisons show unavailable until a
  compatible baseline exists.
- Check the latest-change, seven-day, and today widgets after recording and deletion.
- Retry App Lock after cancelling or encountering an authentication error.

Background execution remains scheduled by iOS. Counter snapshots cannot recover
individual historical playback events or fill unobserved days. Update all syncing
devices to this version to apply the shared deletion policy consistently.
