# SongBrief v1.0.1 Release Notes

Date: 2026-07-10

Version: 1.0.1

Source build: 2. The TestFlight workflow may assign a newer CFBundleVersion.

Release type: App Store reliability and accessibility update

## Japanese App Store Release Notes

聴取記録の保存とiCloud同期の信頼性を高め、App Lockをより安全にしました。Musicへのアクセスが拒否された場合やライブラリの読み込みに失敗した場合の復旧導線を追加し、チャート、ヒートマップ、設定画面、文字サイズ、ダークテーマのアクセシビリティも改善しています。

## English App Store Release Notes

This update improves the reliability of listening records and iCloud sync, makes App Lock safer, adds recovery actions for Music access and library loading errors, and improves accessibility across charts, heatmaps, settings, text scaling, and dark themes.

## App Review Notes

- Temporary demo data remains separate from listening records and is never uploaded to iCloud.
- When Music access is denied, the app can open iOS Settings so the reviewer can grant access.
- App Lock remains locked if authentication times out or cannot be completed.
- Private iCloud history is removed locally only after CloudKit confirms the deletion.
- Premium purchase UI remains disabled in this release.

## Release Checklist

- Add the `filterSignature` String field to the CloudKit `DailySnapshot` record type and deploy the Development schema changes to Production.
- Restore App Store availability under Pricing and Availability; version 1.0.0 is currently removed from sale.
- Run the TestFlight workflow so Dart coverage and native iOS unit-test gates complete before upload.
