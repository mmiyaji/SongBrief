# SongBrief 1.2.7

## Changes

- Pass the current player's Apple Music catalog ID separately from its local
  persistent ID so registered songs can match despite differing display metadata.
- Validate catalog identifiers consistently across native library mapping,
  playback, history deduplication and library matching. Do not interpret opaque
  MusicKit library IDs as public catalog IDs.
- Prefer the official song URL supplied by MusicKit, including album links with
  a song query parameter, and retain it through cached and persisted history.
- Fall back to Apple Music search when no usable song URL or catalog ID exists.
  Preserve native counters and avoid extra outside-library counts on a match.
