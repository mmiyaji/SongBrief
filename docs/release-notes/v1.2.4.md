# SongBrief 1.2.4

## Changes

- Show recent listening evidence consistently in Playing and the library when
  native last-played dates are stale or missing. Merge MusicKit dates with native
  identities while retaining native counters and library membership.
- Use positive changes between compatible daily records as observation dates.
  Label observations without presenting a guessed playback time. Preserve real
  playback timestamps and do not invent activity from skips, resets or gaps.
- Observe supplemental lifetime aggregates only on the overview and ranking
  screens. Reuse native rankings, search text and unaffected indexes when adding
  supplemental songs instead of rebuilding the full library aggregate.
- Defer recency-adjusted library indexes until the library screen needs them.
- Keep period, rising and rank-change rankings available when supplemental
  songs exist. Use native daily records for these views and identify their scope.

## Validation and Limits

- Local Flutter suite: 331 tests passed; static analysis passed.

  inactive-tab subscriptions, period rankings and stale/missing recency dates.
