# SongBrief 1.2.3

## Changes

- Include confirmed minimum supplemental plays in total plays and rankings.
- Persist distinct song/timestamp observations independently of native library
  counters. Re-fetching an observation does not increment its count.
- Keep undated evidence as one minimum play; replace that minimum when a dated
  observation becomes available instead of counting both.
- Include actual dated supplemental events in the listening calendar. Undated
  evidence is not assigned to a calendar day.
- Prefer native library counters when a song is subsequently matched in the
  library. Respect exclusions and keep native snapshots separate.
- Match Apple Music catalog IDs even when display metadata differs, reducing
  false outside-library classification.
- Retain indexed matching and existing iPad player performance fixes.
