## App Review Notes

SongBrief reads the user's local iOS Music library only after Music access is granted. It uses the metadata and counters exposed by iOS, such as play count, skip count, last played date, artist, album, playlist membership, and artwork.

Daily listening records are stored locally as per-day files. If the user enables iCloud sync, records are stored in the user's private CloudKit database and merged across their own devices. The developer cannot access that private CloudKit database.

The app includes a temporary demo-data mode so reviewers can evaluate the UI if Music access is denied or the test device has no Music library content. Demo data is not saved to listening records and is not synced to iCloud.

The initial release may show modest AdMob banner ads. Premium purchase UI is disabled in this release.

Crash reports are opt-in from the app settings. SongBrief does not intentionally include song titles, artist names, album names, lyrics, playlist names, listening history, or local music library identifiers in advertising, analytics, or crash-reporting payloads.
