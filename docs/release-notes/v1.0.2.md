# SongBrief v1.0.2 Release Notes

Date: 2026-07-12

Version: 1.0.2

Source build: 3

Release type: Performance, responsive layout, playback, and listening-record
reliability update

## Japanese App Store Release Notes

概要画面の表示処理を軽量化し、スマートフォンとiPadでのレイアウトや長い数値・テキストの表示を改善しました。再生中の曲から前後の曲へ移動しやすくなり、曲詳細も再生状態に追従します。複数端末から同期した再生記録の重複を抑え、更新状態や最近の再生傾向も分かりやすくしました。

## English App Store Release Notes

This update makes the Overview screen faster, improves responsive layouts and
long-value presentation on iPhone and iPad, and adds subtle previous/next
controls to the current track. Track details now follow playback changes more
reliably, while multi-device listening-record sync avoids duplicate deltas and
recent listening states are easier to understand.

## App Review Notes

- Music library metadata remains processed on device.
- Daily records may sync through the user's private CloudKit database when
  iCloud sync is enabled.
- The widget reads only a compact summary shared by the main app through its
  App Group.
- Crash reporting remains controlled by the user's in-app setting and does not
  intentionally include music-library metadata.
- Premium purchase UI remains disabled in this release.
